❓ Frequently Asked Questions ❓ 常见问题 (FAQ)

🔹 Clipboard not saving / Permission issues

Go to System Settings → Privacy & Security → Accessibility and ensure PastePal is checked. Also check "Clipboard" permission. If still not working, try restarting the app or re-grant permissions.

🔹 Sidebar won't show / Shortcut not working

Default shortcut is ⌘⇧V. If it conflicts with another app, you can change it in Settings → Shortcuts (click menubar icon). You can also show/hide the sidebar via the menubar icon.

🔹 iCloud sync fails or inconsistent across devices

• Make sure all devices are signed in to the same Apple ID and iCloud Drive is enabled.
• Turn on "iCloud Sync" in PastePal settings and wait a few seconds.
• If still not working, try toggling sync off and on again, or restart the app.

🔹 Double‑click paste doesn't work / pastes when no cursor

Double‑click paste requires a valid text cursor (e.g., in an input field) and Accessibility permission granted. If no cursor is detected, double‑click will only copy the item. You can always single‑click to copy and then paste manually.

🔹 How to completely clear history?

Right‑click the menubar icon → "Clear History", or enable "Clear on quit" in Settings. This removes all data and preview caches immediately; cannot be undone.

🔹 剪贴板无法自动记录 / 权限问题

请打开 系统设置 → 隐私与安全性 → 辅助功能，确保已勾选 PastePal。同时检查“剪贴板”权限是否开启。若仍未解决，尝试重启应用或重新授予权限。

🔹 边栏唤不出 / 快捷键无反应

默认快捷键为 ⌘⇧V，若与其他应用冲突，可点击菜单栏图标进入 设置 → 快捷键 修改。也可通过菜单栏图标手动显示/隐藏边栏。

🔹 iCloud 同步失败或设备间不一致

• 确认所有设备已登录同一 Apple ID 并开启 iCloud 云盘。
• 在 PastePal 设置中打开“iCloud 同步”开关，等待几秒同步触发。
• 若仍无效，尝试关闭同步再开启，或重启应用。

🔹 双击无法粘贴 / 无光标时误操作

双击粘贴需要系统检测到有效的文本光标（如在输入框内），且已授予“辅助功能”权限。若无光标，双击只会复制内容而不粘贴。您也可以使用单击复制后手动粘贴。

🔹 如何彻底清空历史记录？

点击菜单栏图标右键 → 清空历史记录，或在设置中开启“退出时自动清空”。清空操作将同时移除所有预览缓存，无法恢复。

📋 Troubleshooting Tips 📋 自行诊断小贴士

If you encounter unusual behavior, try these steps:

如果遇到奇怪行为，可以尝试以下步骤：

  • Restart PastePal (completely quit and reopen)
  • 重启 PastePal（完全退出后重新打开）
  • Check if macOS version ≥ 12.0 (Monterey)
  • 检查 macOS 版本是否 ≥ 12.0 (Monterey)
  • Look for red badge on menubar icon indicating permission issues
  • 查看菜单栏图标是否有红色角标提示权限问题
  • For sync issues, check logs (⌥‑click menubar icon → Open Log Folder)
  • 若问题与同步相关，可查看控制台日志（按住 ⌥ 点击菜单栏图标 → 打开日志文件夹）
